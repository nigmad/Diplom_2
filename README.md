# Diplom_2

# Отчёт о тестировании API для Stellar Burgers


## Описание тестов

### 1. Создание пользователя

1. **Создание уникального пользователя**
   - Тест прошёл успешно, API вернуло статус 201, и пользователь был создан.
   - **Результат**: успешное создание пользователя.

2. **Создание пользователя с уже зарегистрированным логином**
   - Создание пользователя с логином, который уже существует в системе. API вернуло ошибку с кодом 403.
   - **Результат**: ошибка 403 — логин уже занят.

3. **Создание пользователя без обязательного поля**
   - При попытке создать пользователя без обязательного поля (например, без имени) API вернуло ошибку с кодом 400 (плохой запрос).
   - **Результат**: ошибка 400 — обязательные поля не заполнены.

### 2. Логин пользователя

1. **Логин под существующим пользователем**
   - Логин в систему с правильно введёнными логином и паролем. API вернуло статус 200 и токен авторизации.
   - **Результат**: успешный логин, статус 200.

2. **Логин с неверным email и паролем**
   - Логин с неверным email и/или паролем. API вернуло ошибку 401 (неавторизован).
   - **Результат**: ошибка 401 — неправильные данные.

### 3. Изменение данных пользователя

1. **Изменение данных с авторизацией**
   - После успешной авторизации изменение имени и email пользователя. API вернуло статус 200, и данные были обновлены.
   - **Результат**: успешное изменение данных с авторизацией.

2. **Изменение данных без авторизации**
   - Изменение данные пользователя без авторизации. API вернуло ошибку 401 (неавторизован).
   - **Результат**: ошибка 401 — требуется авторизация.

3. **Проверка изменения всех полей с авторизацией**
   - Я проверил возможность изменения всех доступных полей пользователя (email, имя ) с авторизацией. Все изменения прошли успешно.
   - **Результат**: успешное изменение всех полей.

4. **Проверка ошибки при изменении данных без авторизации**
   - При попытке изменить данные пользователя без авторизации API вернуло ошибку с кодом 401.
   - **Результат**: ошибка 401 — требуется авторизация.

### 4. Создание заказа

1. **Создание заказа с авторизацией**
   - Создание заказа с авторизацией, указав ингредиенты. API вернуло статус 201, и заказ был успешно создан.
   - **Результат**: успешное создание заказа.

2. **Создание заказа без авторизации**
   - Создание заказа без авторизации. API вернуло ошибку 401 (неавторизован).
   - **Результат**: ошибка 401 — требуется авторизация.

3. **Создание заказа с ингредиентами**
   - Создание заказа с набором ингредиентов. API вернуло успешный ответ с кодом 201 и ID заказа.
   - **Результат**: заказ с ингредиентами был успешно создан.

4. **Создание заказа без ингредиентов**
   - Создание заказа без ингредиентов. API вернуло ошибку 400 (плохой запрос).
   - **Результат**: ошибка 400 - плохой запрос

5. **Создание заказа с неверным хешем ингредиентов**
   - При создании заказа с неверным хешем ингредиентов API вернуло ошибку 400 (плохой запрос).
   - **Результат**: ошибка 400 — неверный хеш ингредиентов.

### 5. Получение заказов пользователя

1. **Получение заказов авторизованного пользователя**
   - Получение заказов авторизованного пользователя. Ответ был успешным, возвращены все заказы.
   - **Результат**: успешное получение заказов пользователя.

2. **Получение заказов неавторизованного пользователя**
   - При попытке получить заказы без авторизации API вернуло ошибку 401 (неавторизован).
   - **Результат**: ошибка 401 — требуется авторизация.
